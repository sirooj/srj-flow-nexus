# SRJ defect workflow

First read the current full source [`srj-defect/SKILL.md`](../../../.opencode/skills/srj-defect/SKILL.md). Classify the defect using its taxonomy before writing. Gather disk evidence, identify cause and fix, and update the owning workflow skill when the source requires it. Preserve unrelated dirty work.

When a known class recurs, distinguish a missing gate from a gate that was bypassed or too weak. Repair the artifact, then tighten the owning workflow entry so its proof must pass before the success claim; avoid duplicating the symptom as another long anecdote. Record the proving command and saved-file result in the required ledger or handoff. A phantom turn - a filing turn whose staging trail is absent - re-files before any grade; numbers from an unexecuted turn are withdrawn, never re-cited. File the outcome: the next ledger number (tail-append, counted first, never assumed) with class plus cause plus correction plus the proving command, and refresh the pointer's State and Next.

A defect workflow does not authorize strategy changes, code builds, tester runs, or external messages. Route semantic rulings through the authorized council/operator path and retain the active task's scope.

**D19 INFERRED-PREMISE DISPOSITION (owner: srj-defect; added 2026-10-03 after a two-round waste).** A page disposition that a reviewer then flags as ungrounded - "this declaration rests on a reading the operator never stated" - is this class, whatever the disposition is called. Three mechanical parts: (a) a declaration whose support is INFERRED rather than quoted or cited is marked INFERRED-PREMISE on the page and may not be treated as settled, swept, or used to strike text until the premise is tested against the operator's recorded words; (b) a sweep that strikes text a later ruling makes CORRECT is a bypassed gate, not a correction - the sweep is BLOCKED and the struck text restored; (c) when the operator rules on scope, the audit verifies the applied scope against his QUANTIFIER ("all six", "both", "every"), because narrowing a ruling to one instance or a subset is the failure mode that cost the v408 and v409 rounds here. The paired gate lives in srj-council (OPERATOR-RULING FIDELITY). A scoping question framed as a binary his words already decide is this class too: it is a record-first failure, because the words were on disk.
