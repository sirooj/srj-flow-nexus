# SRJ strategy rules

This skill is SRJ-only. Do not use it to judge HORC or another strategy. Strategy meaning comes from the SRJ specification and your later rulings; code and council prose cannot redefine it.

Before an SRJ strategy interpretation, read the complete current source [`srj-strategy/SKILL.md`](../../../.opencode/skills/srj-strategy/SKILL.md) and its full-read/count requirement. Then consult the relevant specification, restatement, finding, and journal evidence in the prescribed order. Resolve later amendments explicitly and never invent a rule from code behavior.

For implementation or relay work, also load `$srj-council`; strategy authority and implementation clearance are distinct gates.
