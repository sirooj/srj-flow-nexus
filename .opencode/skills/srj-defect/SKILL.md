# /srj-defect — common-mistake self-audit and repair

Deploy by typing `/srj-defect` and pointing at the mistake (paste the report line or name the artifact). The builder then STOPS all other work and runs this protocol. No new writes until the defect is classified below.

## 0. Strategy scope (portfolio rule 2026-09-29 - taxonomy is neutral, sources swap)

- The D1-D17 classes below are STRATEGY-NEUTRAL: a hand-typed row is D4 whether the row is SRJ or HORC; a mid-file landing is D6 in any file.
- D1 record-first SOURCES swap per declared strategy: SRJ blocks search spec Part A v4.2, restatement, findings, journal; HORC blocks search the vault glossary, the vault spec, the note that raised the question, then his words. A question one strategy's record answers is that strategy's D1 - never answered from the other strategy's record.
- Cross-strategy attribution (an SRJ pin judging a HORC take, a HORC note entering an SRJ relay) is D3 by canon-order: each strategy's spec plus his later words govern that strategy alone.
