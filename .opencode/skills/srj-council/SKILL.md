# srj-council - builder-as-council pre-transport review

Role: the builder attacks its own draft as a reviewer BEFORE the operator carries anything to a council seat. This pass never rules, never clears, never substitutes for dual-key. Same author, same blind spots - proven 2026-09-19 when the v191 battery passed green and Luna caught the 83/106 contradiction the same turn.

## 0. Strategy scope (portfolio rule 2026-09-29 - names stay, reach widens)

- This battery is STRATEGY-NEUTRAL: every gate fires for any strategy's transport drafts (SRJ today, HORC from its Phase 7, future strategies the same way). Skill file names stay `srj-*` - renaming would break ledger/history pointers, so scope widens by this section, never by rename.
- File-bound gates (twin, snippet, EA-#### cites, P-sequence, digest freshness) resolve against the block's DECLARED strategy files (AGENTS.md STRATEGY-CONTEXT): SRJ drafts cite the SRJ tree, HORC drafts cite the HORC tree. A gate citing the wrong strategy's files is itself a defect.
- Learning-phase artifacts (vault notes, glossaries, draft specs) NEVER enter this battery - they carry no packets, no keys, no transport signal. The battery's first question on any draft is which strategy it serves; a draft serving none is out of order.

## 1. Entry conditions (all must hold)

- Draft filed on disk (packet and/or relay). A P-block relay is twin-verified first.
- No transport has happened for this version. Nothing half-sent.

## 2. Attack loop (repeat until a full pass finds zero disk-proven defects)

1. Re-derive every number from disk (envelopes, margins, counts, digests). The machine enumerates; hands never add. No mental arithmetic.
2. Adoption-needs-anchor: every verdict fold names its packet anchor (line plus old-to-new). Zero hits means the claim is false and the packet gets the anchor, never the reverse.
3. Leftover sweep: every deleted or renamed concept (old versions, old numbers, old digests, old questions) proven zero outside explicit history. Presence counts never substitute for absence counts.
4. Prose-vs-block parity: every prose paraphrase of a block figure re-grepped against the block after every resync.
5. D14 self-checks: declarations, initializers, and assignments recounted mechanically; frozen regex diffed against its rejection list; scope wording read against siting; every record type fingerprinted; every terminal branch proven separately.
6. Fix only what disk proves. A fix landing in history is reverted the same turn.
