# /srj-defect — common-mistake self-audit and repair

Deploy by typing `/srj-defect` and pointing at the mistake (paste the report line or name the artifact). The builder then STOPS all other work and runs this protocol. No new writes until the defect is classified below.

## 1. Classify first (no writes before this)

Match the mistake to one class. If none fits, say so and stop — do not force a fit.

- D1 ASK-BEFORE-SEARCH: a question was asked that the record already answers. Sources in order: spec Part A v4.2 (cited section), restatement, findings, journal, ALL other filed prose (decision memos, relays, results, session prompts). A search of journal-only is NOT a search. V4 2026-09-17 TIGHTENING (A2/A3 kills): his DECLINES inventory counts as record — before presenting ANY fire as an open question, grep his prior MUST-DECLINE / considered-not-taken / invalid rulings by bar (v14-SEL1 table, SEP8_MANUAL_REVIEW, v93 quotes) and match bar-for-bar. An ask on a bar he already declined is D1, not a relay. V5 2026-09-18 TIGHTENING (8/28 entry time, third occurrence): entry-time/detail asks check BUILDER_FINDING_0828-FVG.md + COUNCIL_RESPONSE_POI-R.md + journal Comment first — his 2026-09-11 correction already gives entry 1.16466 next-open ~10:05; journal-silent is not record-silent. V6 2026-09-20 TIGHTENING (performance verdicts): before presenting ANY run-performance claim or asking him to judge match-vs-journal, join tester deals against his journal TAKEN rows plus the declines inventory bar-for-bar on record (entries, takes, rejects, misses); a performance verdict without that join is D1. Learned this turn (RECON48: the 'your call' ask withdrawn; the join showed entries 4/4 signaled, takes 3/4, 9/4 winner missed on lot floor, 16:45 false take, 17:00 valid-setup miss).
- D2 DESCRIPTION-ONLY PACKAGE: a relay or ruling ask without whole code regions or machine-pulled rows inline. Any "..." standing in for code, or any claim resting on prose about evidence.
- D3 UNRESOLVED CONTRADICTION: two contradictory standards quoted side by side without resolution. Governing order: spec, then his later words, then council prose. Council prose never overrules him.
- D4 HAND-TYPED EVIDENCE: any row value, price, or ID that was typed rather than machine-pulled, or any token/ID invented. Includes one hand-typed cell in an otherwise pulled table.
- D5 MIXED PROVENANCE: blocks from different eras, runs, or seats without labels. Every block needs run ID plus archive plus date. Old vs new never share a header.
- D6 FILER FAULT: filed twice, appended mid-file instead of tail, duplicated pointer lines, overwrote instead of adopted, or wrote without a same-name collision check. REPEAT 2026-09-18 (ledger 388 after 386, 391 after 389): a generic closing line is never an append anchor — anchor rule lives in the audit below. REPEAT 2026-09-21 (ledger 531: the anchor matched stale mid-file 528 text through the shared generic closing sentence, then the repair script wrote from null-computed strings with no length assertion — 640KB ledger left 1 byte; recovered per his order while the run ran: HEAD base plus capture plus live-context re-file, gap 371-510 labeled unrecoverable; generator-write gate banked in D13 same turn).
- D7 UNNAMED-FILE MEMO: a memo referencing a deliverable without its exact `06_HANDOFFS\NAME.md` path plus read-vs-paste action.
- D8 SCOPE STEER: new dates, windows, instruments, or strategy direction proposed or framed without his explicit order. Includes framing that steers him toward supplying them. V2 2026-09-20 TIGHTENING (current-period-first + time-cost): match his taken trades inside the CURRENT tested window first; never propose recall slices or new windows without his explicit scope order (Amendment 4 states the bar, never the schedule); every recommended run states its machine cost (measured: 2 weeks ~1 h) against the in-period alternative; an uncosted multi-hour recommendation is D8.
- D9 DRIP-FEED: questions asked one by one across turns instead of batched in one decision memo.
- D10 UNMEASURED CLAIM: anything asserted from agent or model prose without a disk measurement (hash, bytes, lines) pasted verbatim. Accusations need measurement first too.
- D11 SINGLE-PROOF ZERO: any void, absence, or miss graded on one unconfirmed zero (one pattern, one flag, one file).
- D12 SCRIPT HYGIENE: non-ASCII in any ps1, or a script-touched file without a raw-byte audit.
- D13 TOOL-MISREPORT: a tool status message contradicting disk state on independent re-check (a "success" that wrote nothing; a "failure" that applied). Learned 2026-09-18: ledger-392 "success" with length and marker counts unchanged; pointer edit "failure" with content present on read-back. Tool results are claims, never facts.
- D14 SELF-REVIEWABLE PAGE DEFECT: a relay bounced for a defect the builder could have caught without council — typed counts disagreeing with the quoted code (declarations/initializations/assignments), a frozen regex contradicting its own rejection list, scope wording contradicting the siting on the same page (C-reach vs post-gate placement; candidates-per-bar vs one-call-per-bar proof), a record-type fingerprint present on some record types but missing on others, or a latch/ordering property proven for one terminal branch but not the other. Learned 2026-09-18 (v174 trip: Astra-A1 two-initialized count; Luna-2/Astra-A3 plus-sign contradiction; Luna-3/Astra-A7 C-reach wording; Astra-A9 missing terminal fingerprints; Luna-5 BSAVE latch gap — all page-checkable, all cost a human trip). REPEAT 2026-09-18 (v175 trip, Opus-B1/B5): frozen probe code used `unsigned int` — not an MQL5 type (zero hits in the EA; hard compile error under the 0/0 gate) — and rested the whole finite taxonomy on `MathIsValidNumber` with zero uses in the EA and unfiled ±Inf behavior. Language keywords and load-bearing library predicates are page-checkable too. REPEAT 2026-09-18 (v178 accuracy audit): SUBSTRING IS NOT A LINE — `SLEXT481` counts 443 as substring but 442 as lines (a LINEWIDTH meta line carries the substring); line claims need per-line regex counts, never substring counts. DOUBLED-WORD SCANS NEED WORD BOUNDARIES — bare `on on` hits `construction`/`only`; scan ` on on ` with spaces. REPEAT 2026-09-19 (v180 trip, packaging battery green throughout: relay-title dir paraphrase vs P034 narrow rule; delta-paragraph 15x40 vs P038 41; adopted dir-join claim with evidence filed but no packet rule sentence; bare `in v16` prose the token sweep missed - prose-vs-page and adoption-anchor gates now run every transport, zero exceptions).

- D14 REPEAT 2026-09-20 (v203 trip, burned relay: E4 DECL block byte-proven against EA L11054-L11055 while labeled L1054-L1055 - the verify compared content to content and never label to content; Sonnet plus GLM burned a full round on it; root cause above the page: no srj-council invocation before the transport signal, ad-hoc checks substituted for the battery; label-content gate banked in srj-council same turn).
- D15 FRICTION-STOP: a turn that ends asking for his proceed/word/object when the next artifact needs nothing from him, ends on a status report while fold/relay-build/battery work remains open, or ends with a completed list while the workflow still owns a next artifact (the "all done, stopping" close with carrying work unopened). Learned 2026-09-19 (his standing order - he adds no input or objection on these steps): stops happen ONLY at his-carrier boundaries (his paste transport, verdict returns, run words, money/goals); everything else runs unattended to transport-ready, across turns if needed, never pausing for permission. ## 2. Audit mechanically (per class, literal commands, paste verbatim)

- D1: grep every source for the question's keywords; file hits and misses per source WITH any further question. If any source answers, the question is withdrawn, never asked.
- D2: list every claim in the artifact; beside each, the inline whole region or pulled rows that carry it. No carrier means the vehicle is withdrawn and re-filed with source inline.
- D3: name both standards plus their sources; apply the governing order; either resolve on record or escalate as ONE question.
- D4: re-pull every row from its journal or log and set-diff against the filed table; re-verify every ID. Correct the record, name the withdrawn error, keep the surviving conclusion, credit the catcher by seat.
- D5: re-label every block (run, archive, date) or re-file cleanly; verify tail order after every append.
- D6: append ONLY anchored on the previous item number plus its exact tail lines, with EOF confirmed (file length plus tail read) BEFORE the edit; after: order-grep proving item numbers sequential at the tail, plus tail read-back. A generic closing line is never an anchor — it matches many entries and misfiles mid-file. Compose multi-line anchors ONLY from a byte-dumped tail (dots-for-spaces render); prefer one short unique single-line anchor. Rendered Read output hides spacing — on any anchor miss, byte-dump first, never re-guess from rendered output (2026-09-18: two multi-line anchors failed on invisible differences; the byte-dumped single line landed). Counts before and after (marker 0 to 1, never 1 to 2); collision list-check before any filed write; adopt-not-overwrite on collision. VERBATIM-STAGE (long verdict pastes ride in temp files with count verification before byte-append; unicode never enters ps1; end-anchored checks with dup-head skip).
- D7: reissue the memo named. A memo with an unnamed file is defective — reissue, don't patch by chat.
- D8: vacate the track the same turn (record stands, nothing built on it); report the vacation plainly.
- D9: collect ALL open questions into one decision memo; ask once.
- D10: produce the hash, byte count, or line output, or withdraw the claim the same turn. Transport-mechanism words (re-sent, echoed, contaminated, slipped, stale-session, clipboard-slip, duplicate-trip as mechanism) are BANNED from builder verdicts — they describe HIS side of the transport and are never disk-provable: disk proves text-identity only. Rule the filing on identity; send the mechanism question to him with the audit, never as a builder verdict. On any "I sent X not Y" challenge the audit MUST reconcile in ONE paragraph with SIX fixed lines, all from disk: (1) his message title quoted verbatim, (2) filed X entry headers with file plus line numbers, (3) Y-only strings in his paste with entry line numbers, (4) the both-true sentence (X round complete on disk AND this paste carries Y texts — the paste and the relay it describes are different rounds), (5) filing kept unchanged (zero-new-marker stands under every mechanism), (6) ONE confirmation question only (is the filed X set his X round?). A second dispute turn on mechanism is itself a D10 repeat — dispute capped at one paragraph plus one question. Learned 2026-09-18 (ledger 406/407/408: a correct zero-new-marker filing still cost a full dispute turn — 30-min thinking plus 10-min Opus per cycle — by arguing mechanism across three turns instead of reconciling from already-disk facts).
- D11: re-prove with a second differently-formed pattern before grading anything on it.
- D12: rewrite ASCII-only; file the byte audit (non-ASCII count plus line-ending note). QUOTING (2026-09-18: a helper script written with backslash-escaped quotes `\"` failed to parse — ps1 takes plain quotes only, `\"` is backslash-plus-quote, never an escape): Write-tool content carries plain `"` characters, never `\"`; prefer single-quote style plus `[char]10`/`[char]13` over double-quoted backtick escapes so the script parses exactly as written. CASE-COLLISION (2026-09-19: `$p` loop var silently overwrote `$P` path var - PowerShell is case-insensitive, so the write failed with a lying PathTooLong error): loop variables never share a name with path/state variables even in different case; on any bizarre .NET error, suspect the variables first, re-read the script, never trust the message.
- D13: re-verify EVERY file write by independent means (marker counts, file-length delta, tail read-back) regardless of the reported status; on mismatch, repair to disk-truth and name the misreport in the ledger. Never re-issue a blind write on top of a failure message — read state first, then decide. OUTPUT-PROOF (2026-09-19 v184 trip: the build script exited 0 with correct twin numbers, but head edits had landed in a joined-string copy while output assembled from the original array - the stale L13 shipped inside a "green" build): script-exit plus partial numbers never verify a build; after every generator run, grep the OUTPUT FILE for every rep'd sentence (new-phrase present 1x, old-phrase 0x outside history) before any battery claim. A green log with an unverified file is unwritten work. GENERATOR-WRITE GATE 2026-09-21: no scripted WriteAllText executes unless every computed string already proved non-empty with an explicit length assertion beside it (expected length stated before the write, actual pasted after); a repair script that deletes-then-writes proves the deletion span first (both boundary indexes pasted); on ANY exception mid-script the file is re-read before any further write — never a blind write on top of a failure message.
- D14: recount mechanically (declarations, `=` initializers, B assignments — diff-shape numbers derived, never typed); quote the frozen regex once and diff it against the rejection list character by character (`+`, zero forms, exponents); read the C-reach sentence against the siting sentence and the scope sentence against the one-call proof; list every record type and check format+pkt identifiers on each; list every terminal branch and check latch+ordering on each. Fix all hits before the relay is filed — a council bounce on any of these is a repeat D14. REPEAT 2026-09-18 (v177 trip): prove every terminal class reachable-or-impossible from the order+counter (a "first-X" class the counter forbids is a page error, not a grading rule); count payload positions mechanically from the frozen list (a seat's position claim is itself a claim — the v14 "34 vs 35" dispute settled 34 by enumeration); "immutable" is forbidden for repopulated arrays (single textual definition site); brace depths recorded as literal numbers for both insertion sites. SENTENCE-JOIN SCARS (v16: replacements ending in periods where the original continues with one print `..`; copy/paste duplicates whole paragraphs - B1x2 caught pre-append, triage echo; read back every joined region whole). ANCHOR-SURPRISE (an anchor counting 0/2/3 instead of 1 is evidence, never forced: S6 identical rule in two places, B1 third hit history; adjudicate each).

- D15: list the turn's open todos plus, for each, the physical action ONLY he can perform (paste transport, verdict return, run word, money call); any todo answerable disk-side stays open and the work continues the same turn - a status-only ending with open builder-side todos is the defect, repaired by continuation, never by a permission ask. Todo lists never carry await-word items; they carry the next work, and a turn break with carrying todos is scheduling, never a stop.

## 3. File and report (every deployment)

- Ledger: next number in `SRJ_FlowNexus_Local\06_HANDOFFS\BUILDER_LEDGER_QUEUE.md`, tail-append only, format `332. /SRJ-DEFECT <class> + <one-line cause> + <correction> + <withdrawn artifact, if any> + NO build/run/commit` (or the real next number — count first, never assume).
- Pointer: refresh `BUILDER_SESSION_POINTER.md` State plus Next (single action), dedupe the Next block, keep under 35 lines, verify by read-back.
- Report to him: plain words, short sentences. What was wrong. What the record actually says. What is withdrawn. Next action. Name every file exactly. Never bare row numbers. Gloss every EA code. No new question unless the audit proves true absence — and then the audit rides with it.
- This skill learns: a defect seen twice gets its audit tightened here the same turn (no chat-only lessons).
