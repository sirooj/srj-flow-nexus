## 0. Status

v3 is superseded, not amended. It contains five classes of error a patch cannot fix:

1. It treats "POI interaction" as one concept. It is three, and conflating them made the 8/17 exit unreadable from the record.
2. It uses one word — *bias* — for two unrelated objects.
3. It specifies no exit model, while every journalled outcome is entry plus exit.
4. Several rules have been overturned by operator ruling since it was written.
5. It reasoned about zone selection from the orchestrator's chosen zones rather than the operator's, and treated coincidence of session and direction as evidence of agreement. §9.7 records the consequence.

This document is **specification only.** §8 marks what the current build implements. §9 states what is not known.

**Standing prohibition, governing everything below.** No minimum distance, size, width, depth, or bar count for any structure, ever. Validity is structural or geometric, never dimensional. The only permitted numbers are safety limits matching existing precedent: the 500-slot walk bound and the one-point distinctness test. **If a proposed rule needs a number, the rule is wrong.**
