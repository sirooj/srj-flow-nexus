# BRIEF — finishing faster: the full leverage list (2026-09-16, his question)

## Where the time really goes (ranked)

1. COUNCIL ROUNDS (biggest): each relay costs his paste + two council turns + free-tier budget. A full build→run→grade→next-step cycle eats 2-4 pastes. Cutting one round saves more wall-clock than any machine tweak.
2. RUN HOURS (fixed): ~50 min tick-data compute per run, frozen range, unchangeable. Spend each hour heavily (rider rule, item 226).
3. BUILD/GRADE TURNS (small): minutes each, already mechanical. Nothing to win here.

## Standing rules adopted this turn (all cheap, all compounding)

- DISK-BEFORE-RELAY: no relay asks anything the disk can answer. Every disk-answerable flag is resolved + filed BEFORE the relay cuts, so council never spends a round on builder-measurable facts (this turn's v96 flags were resolved same-round; henceforth they resolve pre-relay).
- CLEARANCE-ON-SIGHT SHAPE: every authorship relay carries quotable clearance text + build gates + grade contract + full branches, so clearance takes one round, never two.
- DURING-RUN DRAFTING: while a run ticks (unattended ~50 min), the next relay/packet text is drafted, so grading day cuts the relay the same turn with zero idle gap.
- CRITICAL-PATH ONLY: every relay names the stage it advances (D/E/F to GOAL-MET) and parks the rest in one parking line. No nice-to-have ever rides a relay.
- RECORD-FIRST SELF-AUDIT: every relay carries one line stating the record-first search ran and what it closed (seven past defects of asking the record).
- RUN-COST HEADER (for council, from the next relay on): every run-bearing relay opens with the standing cost note (tick-data ~1h, frozen range) + the count of questions this round settles, and asks all streams to rule on every item in one round. Batching is stated as practice; council may object to any rider by name.

## What will NOT change (said plainly so it is never re-asked)

- Dual-key + tokens for selection/landing/commits. Print-only already runs the fast path (Luna key + word). Weakening the rest buys speed with safety money — declined in advance.
- One-run-one-scope for behavior changes (rider rule covers print-only only).
- The frozen range (run length permanent).

## Scoreboard to watch

Questions settled per council round (target: rising), rounds per stage (target: falling), wasted runs (stays ~0). If a relay settles nothing new, it was a defective relay.
